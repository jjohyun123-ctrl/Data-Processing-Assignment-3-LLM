# 🚢 JO-PT — 오픈소스 LLM 채팅 프로그램

데이터처리개론 (2026-2학기) · 조선해양공학과 조현영

오픈소스 LLM **EXAONE 3.5 (2.4B)** 를 내 컴퓨터에 설치해서 대화하는 웹 채팅 프로그램입니다.
LLM이 각자의 컴퓨터 안에서 실행되기 때문에, 아래처럼 설치한 뒤 실행해야 합니다. (인터넷 서버·API 키·비용 필요 없음)

---

## 실행 방법 (Windows)

**① 미리 설치할 것 2가지**

| 프로그램 | 다운로드 | 참고 |
|---|---|---|
| Python 3.10 ~ 3.13 | https://www.python.org/downloads | 설치 첫 화면에서 **"Add python.exe to PATH"** 체크 |
| Ollama | https://ollama.com/download | 설치 후 로그인은 안 해도 됩니다 |

**② 코드 내려받기**

이 페이지 위쪽 초록색 **`<> Code` → `Download ZIP`** → 내려받은 zip을 **압축 풀기**

**③ 실행**

압축 푼 폴더에서 **`JO-PT` → `JO-PT`** 로 들어가 **`JO-PT_run.py` 를 더블클릭**

- 처음 실행할 때 필요한 패키지 설치와 LLM 모델(약 1.6GB) 다운로드가 **자동으로** 진행됩니다. (몇 분 소요)
- 준비가 끝나면 브라우저에 **JO-PT** 채팅 페이지가 열립니다. (`http://localhost:8501`)
- 한 번 실행한 뒤에는 바탕화면의 **`JO-PT 실행`** 또는 cmd에서 **`jopt`** 만 입력해도 켜집니다.
- 더블클릭으로 안 열리면 cmd에서:
  ```
  cd 압축푼폴더\JO-PT\JO-PT
  py JO-PT_run.py
  ```

## 실행 방법 (Mac)

1. Python, Ollama 설치 (위 표와 같음)
2. `Code → Download ZIP` → 압축 풀기
3. 터미널에서:
   ```
   cd 압축푼폴더/JO-PT/JO-PT
   python3 JO-PT_run.py
   ```

## 사용해 보기

| 채팅 입력 | 동작 |
|---|---|
| `안녕? 너는 누구야?` | 챗봇 JOBOT 자기소개 |
| `선형회귀가 뭔지 한 줄로 설명해줘` | EXAONE이 직접 답변 |
| `과제1 회귀분석 실행해줘` | 과제1(선형·비선형 회귀) 실행, 결과·그래프 |
| `과제2 인공신경망 실행해줘` | 과제2(인공신경망) 학습, 선형회귀와 비교 |

- 노트북(CPU)에서는 답변 하나에 수 초 정도 걸립니다. 첫 질문은 모델을 불러오느라 조금 더 걸립니다.
- 권장 사양: 메모리(RAM) 8GB 이상
