# 🚢 JO-PT — 오픈소스 LLM 채팅 프로그램

데이터처리개론(2026-2학기) 과제 · 조현영 (조선해양공학과)

오픈소스 LLM **EXAONE 3.5 2.4B**를 Ollama로 내 PC에 설치하고,
Python(Streamlit)으로 만든 웹 채팅 페이지 **JO-PT**에서 챗봇 **JOBOT**과 대화하는 프로그램입니다.
인터넷이나 API 키 없이 PC 안에서만 동작합니다.

## 실행 방법 (Windows)

### 1. 설치 (처음 한 번)
| 순서 | 할 것 | 링크 / 명령어 |
|---|---|---|
| 1 | Python 3.13 설치 | https://www.python.org/downloads (설치 시 "Add to PATH" 체크) |
| 2 | Ollama 설치 | https://ollama.com/download |
| 3 | LLM 모델 다운로드 | `ollama pull exaone3.5:2.4b` |
| 4 | 기억(RAG)용 임베딩 모델 | `ollama pull bge-m3` |
| 5 | 패키지 설치 | `py -3.13 -m pip install streamlit requests` |

### 2. 실행
**가장 쉬운 방법:** 폴더 안의 `JO-PT_run.py`를 더블클릭 → 처음 한 번 실행하면 바탕화면에 `JO-PT 실행` 파일과 cmd 명령어 `jopt`가 만들어져서, 다음부터는 그걸 더블클릭하거나 cmd에 `jopt`만 입력하면 됩니다.

직접 실행하려면:
이 폴더를 열고 주소창에 `cmd` 입력 → Enter → 아래 명령어 입력:
```
py -3.13 -m streamlit run chat.py --theme.base light
```
→ 브라우저에 `http://localhost:8501` 채팅창이 열립니다.

### 3. 터미널에서 LLM만 테스트
```
ollama run exaone3.5:2.4b
>>> 안녕? 너는 누구야?
```

## 과제 1·2 연동
채팅에서 말하면 내가 만든 과제 코드가 실제로 실행되고, JOBOT이 그 결과 숫자를 근거로 해석합니다. 결과는 기억(①②③)에 저장되어 나중에 다시 물어봐도 답합니다.

| 채팅 예시 | 동작 |
|---|---|
| `과제1 회귀분석 실행해줘` | 풍속→유의파고 선형/2차 다항 회귀, 회귀식·R²·그래프 |
| `과제2 인공신경망 실행해줘` | 울산항 선박 54,368척으로 길이·너비·깊이→총톤수 신경망 학습, 선형회귀와 비교 |
| `과제 둘 다 돌려줘` | 과제 1·2 모두 실행 |
| `풍속 12m/s면 유의파고는?` | 과제1 모델로 예측 |
| `길이 200 너비 32 깊이 18이면 총톤수는?` | 과제2 신경망·선형회귀로 예측 |
| `아까 과제1 R² 얼마였지?` | 기억에서 찾아 답변 |

**내 데이터로 실행하기** — 원본 과제처럼 어떤 데이터든 넣을 수 있어요.
1. 사이드바 **📂 과제 데이터**에서 CSV 또는 엑셀(xlsx) 파일을 올립니다. (한글 인코딩 cp949, 쉼표 숫자 "1,234"도 자동 처리)
2. 과제1: X·Y 열을 고릅니다. (기본값 = 원본 코드처럼 숫자 열 첫 번째·두 번째)
3. 과제2: 예측할 열(출력)과 입력 열들을 고릅니다. (`general_ann.py`와 같은 방식, 은닉 8 · 100 epoch · 배치 64)
4. 채팅에서 `과제1 실행해줘`, `신경망 돌려줘`, `온도 -140 압력 5 유량 300이면?`처럼 열 이름으로 예측까지 할 수 있어요.
   - 데이터가 적으면 학습이 부족하지 않도록 epoch를 자동으로 늘리고, 아주 크면 시간을 위해 줄입니다. (결과에 표시)
5. `↩ 기본 예시 데이터로`를 누르면 풍속–파고 / 울산항 선박 데이터로 돌아갑니다.

**과제2 하이퍼파라미터 설정** — 원본 코드의 설정 셀(`HIDDEN_NODES`, `EPOCHS`, `BATCH_SIZE`, `LEARNING_RATE`)과 웹사이트의 은닉 노드 슬라이더·학습률 선택처럼 직접 정할 수 있어요.
- 사이드바 **⚙️ 신경망 설정** → `기본값 사용` 끄기 → 은닉층 노드(1~16), epoch, 학습률(0.001~0.1), 배치 크기 선택
- 채팅으로도 가능: `은닉 노드 10개, 학습률 0.03, 에포크 200으로 신경망 돌려줘` (채팅에서 말한 값이 사이드바 값보다 우선)
- 결과에 사용한 설정과 학습 오차 그래프가 함께 나와서 설정별로 R²를 비교할 수 있어요.

- 원본 코드: [과제1](https://github.com/jjohyun123-ctrl/Introduction-to-Data-Processing---Assignment-1-Code-), [과제2](https://github.com/jjohyun123-ctrl/Data-Processing-Assignment-2-ANN-Code)
- 윈도우 **스마트 앱 컨트롤**이 pandas·numpy·scikit-learn 같은 라이브러리 파일을 차단해서, 과제 계산을 **파이썬 기본 기능만으로 직접 구현**했습니다 (`assignments.py`).
  - 과제1: 최소제곱법(정규방정식)으로 선형·2차 다항 회귀 → 원본과 같은 값 (R² 0.948 / 0.991)
  - 과제2: 입력 3 → 은닉 6(시그모이드) → 출력 1 신경망을 순전파·오차역전파·Adam으로 직접 학습, 원본 Keras와 같은 설정 → R² 신경망 0.980 / 선형회귀 0.804 (원본 약 0.97 / 0.80)
  - 그래프는 matplotlib 대신 SVG로 직접 그림

## 기능
- 사이드바에서 **과제1 · 회귀분석**과 **과제2 · 인공신경망**을 각각 따로 파일을 올리고 설정
- 페이지 이름·챗봇 이름·프로필 사진 설정 (`chat.py` 맨 위 `PAGE_NAME`, `BOT_NAME`, `BOT_PHOTO`)
- 스트리밍 출력 (답변이 한 글자씩 바로 표시)
- **대화 기억 (세 가지 방식, 사이드바 '🧠 기억 방식 설정'에서 켜고 끄기)**
  - ① 전체 기억: 지금까지 대화를 통째로 LLM에 전달 (`memory.json`, num_ctx 16384)
  - ② 메모 기억: 답변 후 JOBOT이 중요한 내용을 메모로 정리, 다음 질문 때 먼저 읽음 (`memo.json`)
  - ③ RAG: 모든 질문·답변을 벡터(bge-m3)로 저장해 관련 과거 대화를 검색 (`memory_rag.json`)
  - 답변 아래 "🔎 참고한 기억"에서 무엇을 참고했는지 확인, 사이드바에서 기억 전체 삭제
- 추천 질문 버튼, 대화 초기화, Ollama 연결 상태 표시
- 밝은 테마 고정 (다크 모드 PC에서도 글자가 잘 보임)
- 모델 교체 가능 (`MODEL = "deepseek-r1:7b"` 등)
